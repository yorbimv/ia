# Prompt & Skills

Repositorio centralizado para organizar y escalar el uso de IA en el desarrollo de software. Dividido en dos áreas clave:

## Estructura

### 📂 [prompts/](prompts/)
Carpeta dedicada a **prompts detallados de uso diario**. Aquí se almacenan las instrucciones maestras que configuran el comportamiento de las IAs para proyectos específicos.

**Ejemplos de uso:**
- **DevOps / Infraestructura:** Prompts para generar pipelines de CI/CD, configuración de servidores, scripts de Docker, etc.
- **Arquitectura de Software:** El prompt base que transforma a la IA en un Arquitecto Senior (ver [ai-architect.md](prompts/ai-architect.md)).
- **Frontend / Backend:** Instrucciones específicas para generar componentes, endpoints o validaciones bajo un stack determinado.

### 📂 [skills/](skills/)
Carpeta dedicada al **ecosistema de Skills**. Aquí se guarda todo lo referente a la instalación, gestión y personalización de Skills (módulos de conocimiento) para diferentes IAs.

**Contenido:**
- **Guías de instalación:** Cómo usar `npx skills` y la CLI estándar.
- **Manuales base:** Adaptaciones del manual de arquitectura para cada herramienta (Claude, Cursor, Gemini, etc.).
- **Referencias:** Enlaces a [skills.sh](https://skills.sh/) y la comunidad de skills open-source.
