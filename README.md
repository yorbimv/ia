## Páginas de Referencia

Herramientas y recursos esenciales para el flujo de trabajo con IAs y desarrollo moderno:

| Página | Descripción |
|--------|-------------|
| [**skills.sh**](https://skills.sh/) | Directorio y leaderboard del ecosistema de Skills. Descubre y gestiona skills compatibles con OpenCode, Claude, Cursor, etc. |
| [**npmx.dev**](https://npmx.dev/) | Explorador rápido y moderno del registro de npm. Permite buscar, comparar y analizar paquetes de forma visual e intuitiva. |
